# parmana-connect

Connectors and agent integration for Parmana. Private, in development.

## Planned scope

- Manifest-driven generic connector: describe a REST capability in a manifest, no connector code.
- MCP server that exposes Parmana's `/execute` as agent tools.
- Each connector declares its capabilities, schemas and credential type.

This repo is separate from `parmana-core`, which stays unchanged.
